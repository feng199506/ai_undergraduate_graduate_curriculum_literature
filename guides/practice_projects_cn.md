# 配套实践项目（practice_projects）

> 每个项目都对应本库实际下载的官方教学材料（D 编号为作业/教程/参考仓库快照，A/B 为配套讲义与教材）。环境与许可证依据仓库 README/LICENSE 或官方页面（见 `catalog_cn.csv` 的“环境要求”“许可证”列）。**本轮只整理，不执行任何项目，也未下载数据集与模型权重**；需要数据的项目在“输入”列注明需另行获取。

## 使用建议
- 每个项目开始前先读对应 A/B 资料的相关章节（见 `core_reading_list_cn.md`）。
- 涉及“需另行下载”的数据或权重时，以各仓库 README 为准，注意数据许可证。
- 许可证写“未声明”或“待核实”的材料仅供个人学习，不要再分发。
