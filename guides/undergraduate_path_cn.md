## 第 4 年：方向选修与毕业项目（09–19 选 2–3 个，20）
官方方案普遍要求“AI 核心 + 若干方向选修”（CMU 4 门方向群选修、斯坦福 Track B 两门、清华 CV/NLP/数据挖掘）。建议从下列方向中选 2–3 个：

| 方向 | 本科层次入口课程 | 教材 | 实践 |
|---|---|---|---|
| 自然语言处理 | A09-03 Princeton COS484 或 A09-01 CS224N | B09-01 SLP3、B09-03 NLTK | D09-01、D09-03 |
| 计算机视觉 | A11-05 CMU 16-385、A11-01 CS231n | B11-01 Torralba 等、B11-02 | D11-01 |
| 强化学习 | A13-05 UCL RL（Silver） | B13-01 Sutton–Barto | D13-03 HF Deep RL、D13-02 Spinning Up |
| 机器人 | A14-03 Freiburg 移动机器人 | B14-01 Modern Robotics | D14-02 |
| 信号与时间序列 | A15-02 6.003 → A15-04 Stat153 | B15-03 Think DSP、B15-01 FPP3 | D15-01、D15-02 |
| 图与推荐 | A16-02 CS246 | B16-03 Easley–Kleinberg | D16-02 |
| 数据库/系统 | A04-03 CMU 15-445 | B04-04 OSTEP | D04-01 BusTub |
| AI 伦理与可信 | A18-03 MIT 公平性 | B18-04 Hendrycks、B18-02 Barocas 等 | D18-03 Fairlearn |

**毕业项目方法**（20 群）：
1. 先学 A20-01 Stanford CS197（研究流程、读论文、定问题、实验设计、写作）与 A20-03 工具课；
2. 用 B20-02 Good Research Code 组织代码；按 D20-01/D20-02（ML 代码完整性清单、NeurIPS 论文清单）自查可复现性；
3. 写作参考 B20-04 Knuth《Mathematical Writing》，伦理参考 B20-03 ORI 研究伦理；
4. 相关元研究论文见 20 群 P20-xxx（基线与消融、评测陷阱、数据泄露、可复现性报告）。

## 先修检查清单（进入第 3 年前）
- 线代：能独立完成特征分解、SVD、最小二乘推导（A01-01、B01-02）。
- 微积分：会多元链式法则与梯度、雅可比（A01-02、A01-03）。
- 概率：会条件概率、期望方差、常见分布、中心极限定理（A02-01、B02-01）。
- 编程：能写 300 行以上结构清晰的 Python 程序并用 Git 管理（A04-01、A20-03）。
- 算法：理解复杂度、递归、动态规划、图搜索（A04-02、B04-02）。
